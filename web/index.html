AbuseRadar

Counter-abuse detection and response for a simulated smart-home device cloud. ATT&CK-mapped SQL rules, a LightGBM login-risk model, graph detection for fake-account rings, incident fusion, and Gemini triage behind a grounding guard. Scored on held-out attack campaigns, including evasive variants never seen in training.
